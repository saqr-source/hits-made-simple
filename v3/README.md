# HITS Made Simple · HITS ببساطة — v3.0

Interactive, bilingual (English / Arabic) playbook that teaches Al Safy Group employees and managers to use the HITS Easy Go app, one task at a time, on real app screens.

Preview: https://saqr-source.github.io/hits-made-simple/v3/  (the site root still serves the approved v2.2 until v3 is signed off)

## What's inside
- **Missions**: Get started · My time off · My time & attendance (Employee) and Approve your team's requests (Manager / Approver). Each mission is a bundle of tasks with a progress bar; every task ends with a final question.
- **Points**: 10 for finishing a task, plus 10 for a right answer on the first go. Answer options are shuffled each time. Progress is stored on the device only.
- **Animated phone**: every step shows the real, masked HITS screen in the approved phone plate. A pointer travels to the control, taps, and a spotlight frames it.
- **Same button positions in both languages**: Back is always on the left and Next on the right.

## Files
| Path | What it is |
|---|---|
| `index.html` | Page shell |
| `assets/data.js` | All copy (EN/AR), missions, steps, hotspots and questions. Generated by `tools/build_data.py`. |
| `assets/config.js` | Anonymous Google Form tracking. Leave `formAction` empty to switch it off. |
| `assets/app.js`, `assets/app.css` | App logic and styles |
| `assets/screens/` | Masked, cropped real HITS screenshots (WebP) |
| `tools/` | Build scripts: data, screen masking, offline single-file build |
| `../index.html` | Approved v2.2, still live at the site root |

## Updating
- Change copy or steps: edit `tools/build_data.py`, then run `python3 tools/build_data.py tools/source_v22_content.json assets/data.js`.
- Offline single file: `python3 tools/build_offline.py HITS_Made_Simple_offline.html`.
- Review mode: add `?review=1` to the URL to tag steps still waiting for SME confirmation.
